OPPR BRAND KIT
==============

The Oppr mark: the baseline wordmark "oppr." and the o-monogram icon that
carries the same terracotta dot.

CONTENTS
--------
Open index.html in a browser to view everything together.

assets/
  wordmark-light.svg   oppr. for light backgrounds (ink text, terracotta dot)
  wordmark-dark.svg    oppr. for dark backgrounds (paper text, terracotta dot)
  icon-tile.svg        the app icon / favicon: terracotta-dotted o on the ink tile
  favicon.svg          same as icon-tile, named for favicon use
  icon-bare-light.svg  o. with no tile, for light backgrounds
  icon-bare-dark.svg   o. with no tile, for dark backgrounds

COLOURS
-------
GROUND    #f2f2ed   warm paper background
INK       #15201e   near-black text and structure
HUMAN     #a65032   terracotta, the operator's voice (the dot)
MACHINE   #3e6874   teal, the machine's voice
VERIFIED  #55745e   green, a verified result

TYPE
----
Wordmark: Archivo, 700 weight, letter-spacing -0.04em, lowercase.
UI / labels: JetBrains Mono.

USAGE
-----
- Keep the wordmark lowercase. The terracotta period is the signature; do not
  recolour it or drop it.
- The icon is the first letter o carrying that same terracotta dot. Use the
  tile form for app icons and favicons; use the bare form in-line or where a
  transparent background is needed.
- One accent per mark. Do not add gradients, shadows, or a second accent colour.
- Clear space around either mark: at least the height of the o.

The wordmark SVGs reference the Archivo font. index.html loads it for preview;
for print or environments without Archivo, request outlined (path) versions.
